# ReRev Short Links

Short links and QR codes that live in the client's own Google account. A Google Sheet holds the links and the click log. An Apps Script web app is the backend. A small Netlify site does the redirect and the admin page. No subscription.

Setup wizard: https://rerev-short-links-setup.netlify.app

Folders: `gas/` backend (bound to the template Sheet), `wizard/` wizard sources (wizard.json, steps.js).
