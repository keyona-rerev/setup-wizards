# ReRev Link Page

One clean page of links that counts every click. A Google Sheet holds the page text, the buttons and the click log. An Apps Script web app is the backend. One static file on the client's own Netlify is the page. No subscription.

Setup wizard: https://rerev-link-page-setup.netlify.app

Folders: `gas/` backend (Code.gs, Setup.gs, appsscript.json same as short-links), `page/index.html` the page (tokens `__API_BASE__` and `__BRAND__` are filled by the wizard).
